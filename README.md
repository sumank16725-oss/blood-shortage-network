# BloodBridge – Predictive Emergency Blood Shortage Network

## About
An AI-powered platform to predict blood shortages across hospitals and blood banks.

## Features
- Blood group availability tracking
- Shortage prediction and alerts
- Hospital inventory monitoring
- Blood matching between hospitals
- Expiry tracking
- Demand forecasting
- Regional availability
- Smart recommendations

## Technology
HTML, CSS, JavaScript

## Objective
To identify blood shortages early and coordinate blood resources efficiently.

## Note
This is a hackathon prototype using sample data.
